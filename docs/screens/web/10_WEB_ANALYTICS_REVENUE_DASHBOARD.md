# Web Screen 10: Real-Time Sales, Delivery SLA & AI Analytics Dashboard

## 📌 Overview
The **Real-Time Sales, Delivery SLA & AI Analytics Dashboard** provides high-level executive telemetry on daily revenue, order delivery times, rider performance, and skin diagnostic trends.

---

## 🎨 UI Architecture & Layout Specs

### 1. Key Metric Metric Tiles (KPI Row)
- **Gross Revenue**: Total ₹ sales today + % comparison vs yesterday
- **Average Delivery SLA**: e.g., `8.4 minutes` (Vijayawada Darkstore)
- **AI Diagnostic Scans**: Total completed scans + top detected skin type (*Combination Skin 42%*)
- **Beauty Protection Claims**: Claim rate % (e.g. `0.2%`)

### 2. Analytics Telemetry Charts
- Line chart: Revenue over time (hourly / daily / monthly)
- Bar chart: Top selling skincare categories & AI prescribed routines
- Map chart: Hotspot delivery order heatmaps

Place your trained skin_model.onnx here.

Generated by Phase 5:
  python scripts/export_to_onnx.py \
      --checkpoint checkpoints/skin_model_best.pth \
      --output     checkpoints/skin_model.onnx

Then copy to this directory:
  cp glowvai_training/checkpoints/skin_model.onnx assets/models/skin_model.onnx

Also update metro.config.js to include 'onnx' in assetExts:

  const { getDefaultConfig } = require('expo/metro-config');
  const config = getDefaultConfig(__dirname);
  config.resolver.assetExts.push('onnx');
  module.exports = config;

Then rebuild the native app:
  npx expo prebuild --clean
  npx expo run:android    (or run:ios)
